# Data dictionary

The following fields were identified in the supplied floristic inventory workbook.

| Field | Description |
|---|---|
| `Site` | Survey site |
| `Classe_occupation` | Land-cover/occupation class recorded in the dataset |
| `Placette` | Plot identifier |
| `Espece` | Species name |
| `Auteur` | Taxonomic author field |
| `Genre` | Genus |
| `Famille` | Family |
| `Circonference` | Stem circumference |
| `Diametre` | Stem diameter |
| `Aire_basale` | Basal area |
| `Hauteur` | Tree height |
| `Type_bio` | Biological type |
| `Type_choro` | Chorological type |
| `UICN` | IUCN conservation-status field |
| `Statut_CITES_Oui_Non` | CITES status indicator |
| `Annexe_CITES` | CITES appendix field |

The exact units, coding conventions, missing-value conventions, and filtering rules should be taken from the study protocol and the analysis notebook rather than inferred from the column names alone.
